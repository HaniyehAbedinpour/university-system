# 🎓 University Management System

A Django-based web application for managing university data such as students, departments, and administrative workflows.

---

## 🚀 Project Overview

This project is designed to simulate a basic university management system using Django.  
It provides a structured backend with models and admin interface for managing academic data.

---

## ✨ Current Features

- Student management system
- Department management system
- Django admin panel configuration
- Clean project architecture (Django apps separation)

---

## 🛠 Tech Stack

- Python 3
- Django Framework
- SQLite (default database)
- Django Admin Interface

---

## 📊 Project Status

Early development stage.  
Core models and admin panel have been implemented, and new features will be added step by step.

---

## 🔮 Future Improvements

- Enrollment system
